# 0001 · 对话内搜索（chat-search）

## 背景与问题

长会话里回看某句话只能滚动翻找；宿主没有内置的会话内搜索。需要在当前会话正文里快速定位关键词，又不打断阅读位置。

## 目标

- 会话内用 `Ctrl+F` 或会话头按钮打开浮动搜索条。
- 输入即搜，命中在正文上高亮，可上一个/下一个并滚动到可见位置。
- 支持区分大小写、全词、正则三种匹配；非法正则只提示，不抛错。
- 记住最近查询，可一键回填。
- 搜索条外观（透明度、毛玻璃、高亮强度）可在插件详情页配置并持久化。
- 默认搜索用户提问、最终回答和过程说明（含折叠部分，见 0002）；思考流与工具调用不参与。

## 非目标

- 跨会话 / 全局搜索。
- 替换、导出命中列表。
- ~~自动展开折叠的过程分组去定位隐藏命中~~（已由 0002 实现：过程开启时包含折叠并自动展开）。
- 搜索图片、附件或代码块里的文件名。

## 行为与验收

| # | 行为 | 验收 |
|---|---|---|
| 1 | `Ctrl+F` 打开搜索条；`Esc` 先关历史下拉，再关搜索条 | 按键后浮条出现/消失 |
| 2 | 输入关键词 120ms 后出结果，计数显示 `当前/总数` | 输入后计数变化 |
| 3 | 回车下一个、`Shift+Enter` 上一个，命中滚动到视口中央 | 循环切换，高亮跟随 |
| 4 | `Aa` 区分大小写、`W` 全词、`.*` 正则；正则非法时占位提示「正则无效」 | 开关切换后结果变化，非法正则不抛错 |
| 5 | 「过程」开关控制是否包含过程说明（含折叠部分），默认包含 | 关掉后同一关键词命中减少 |
| 6 | 历史下拉列出最近 20 条，点击回填 | 关掉再打开仍在（localStorage） |
| 7 | 插件详情页「配置」可改透明度、毛玻璃模糊、命中高亮强度，保存后立即生效 | 保存后搜索条外观变化 |
| 8 | 留空保存等于恢复默认；非数字阻止保存并提示 | 清空后回到默认值，非法输入不能保存 |
| 9 | 过程开启时，折叠的过程正文也参与搜索并在定位时自动展开 | 折叠状态下能搜到并展开 |

## 影响面与风险

- slot：`conversation.session.header.utilities`（入口按钮）、`plugins.row.config`（配置页）。
- Config：`chat-search` 命名空间的 `transparencyPercent` / `blurPx` / `highlightPercent`，全部 `volatile`；设置服务只服务带 volatile 字段的条目。
- 宿主 DOM 契约：`[data-chat-flow-kind]`（`user` / `steering` / `assistant-step`）、`data-chat-group-part`、`data-turn-process-member`、`data-turn-process-answer`、`data-step-process-body`、`hidden`。宿主改这些标记会让搜索范围退化（仍可用，但可能少搜或多搜）。
- 风险：单次搜索最多 400 条命中，超长会话的常见词会被截断；正则搜索在大文档上可能变慢。
- 回滚：关闭插件行或卸载 bundle，配置页与搜索条一起消失，不残留宿主状态。
