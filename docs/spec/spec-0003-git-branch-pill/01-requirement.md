# 需求

## 背景与问题

写代码时经常要确认“现在在哪个分支、这个会话改了多少”。切到终端跑 `git status` 会打断对话；宿主状态行只有轮次、缓存命中和上下文，没有仓库信息。

## 目标

- 状态行左侧显示当前分支名与图标。
- 点击弹出面板：分支、新增、删除、未跟踪文件数。
- 数据来自会话工作目录所在仓库，子目录会话也能定位仓库根。
- detached HEAD 显示短 SHA；非 git 仓库给出可见的错误态。
- 面板可刷新，不阻塞输入。

## 非目标

- 不做写操作（提交、暂存、切换、推送）。
- 不列出逐文件改动或 diff。
- 不跨仓库聚合。

## 验收标准

| # | 可观察行为 | 验收方式 |
|---|---|---|
| 1 | 仓库会话显示分支名与图标 | pill 在状态行最左 |
| 2 | detached HEAD 显示 7 位短 SHA | `git checkout <sha>` 后可见 |
| 3 | 点击面板显示分支/新增/删除/未跟踪 | 与 `git status` 数字一致 |
| 4 | 点击外部或 `Esc` 关闭面板 | 两种方式都能关 |
| 5 | 每 8 秒刷新，打开面板立即刷新 | 改动后数字变化 |
| 6 | 非仓库 / 无目录时 pill 用红字显示错误码 | 悬停见完整错误 |
| 7 | 子目录会话仍显示所属仓库信息 | 在 `packages/xxx` 下开会话 |
| 8 | 无首个提交时统计暂存改动 | `git init` + `git add` 可见数字 |
| 9 | 未跟踪目录按文件计数（`-uall`） | 计数等于文件数 |
| 10 | Remote 不可用时退化为读 `.git/HEAD` | 仍能看到分支名 |
