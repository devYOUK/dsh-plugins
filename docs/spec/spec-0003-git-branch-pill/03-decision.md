# 决策

| # | 决策 | 备选 | 结论 | 理由 |
|---|---|---|---|---|
| D1 | 走 Typert Remote 而不是自定义 HTTP | 注册 `/api/gitPill` 路由 | 采用 `TypertRemoteService` | 与宿主鉴权/传输一致，少一套路由 |
| D2 | 未跟踪计数用 `-uall` | 默认 `git status` | 采用 `-uall` | 默认会把未跟踪目录折叠成一行，计数失真 |
| D3 | 错误态在 pill 内用红字显示错误码 | 保持 `?` + 悬停提示 | 采用红字错误码 | 不点开也能看到失败原因 |
