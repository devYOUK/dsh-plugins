# 需求

## 背景与问题

侧栏工作区行只有「…」按钮（重命名/删除）；打开工作区目录、标记常用工作区、改名都需要先找小按钮。宿主没有工作区行的右键菜单 slot，也没有 contextmenu 处理。

## 目标

- 工作区行右键弹出菜单：用文件资源管理器打开、添加/取消收藏、重命名。
- 打开目录走 Host 原生 opener；失败给出可见提示。
- 收藏后名称染成 DSH 主题蓝并加粗；再次打开菜单显示「取消收藏」。
- 重命名预填当前标题，空值禁用，失败在对话框内提示。
- 菜单在外部点击、`Esc`、滚动、窗口失焦时关闭；非工作区区域右键不拦截。

## 非目标

- 不改工作区删除、排序、新建与分组。
- 收藏不参与排序、不置顶、不跨设备同步。
- 不处理会话行右键菜单。

## 验收标准

| # | 可观察行为 | 验收方式 |
|---|---|---|
| 1 | 右键工作区行弹出三项菜单 | 位置不超出视口 |
| 2 | 「用文件资源管理器打开」打开该目录 | Explorer 定位到路径 |
| 3 | 打开失败时显示错误提示 | 出现 toast，菜单关闭 |
| 4 | 「重命名」弹出预填标题的输入框 | 自动聚焦 |
| 5 | 确认后侧栏标题更新；空白禁用 | 标题变化 |
| 6 | 外部点击/`Esc`/滚动/失焦关闭菜单 | 四种方式均关闭 |
| 7 | 非工作区行右键不拦截 | 原生右键菜单照常 |
| 8 | 「添加收藏」后名称变主题蓝并加粗，菜单显示「取消收藏」 | 文字样式变化 |
| 9 | 「取消收藏」后恢复默认样式 | 颜色与字重恢复 |
| 10 | 刷新页面后收藏仍在 | 名称仍是蓝色加粗 |

## 影响面

- slot：`shell.overlay`（`id: workspace-menu`）。
- 宿主 DOM 契约：`data-row-key="workspace:<workspaceId>"`，标题元素 class 含 `title`。
- 服务：`ctx.workspaces.rename`、`ctx.remote.session.openWorkspacePath`。
- 存储：`localStorage` 的 `dsh-workspace-menu:favorites`。
